Là gì

Biến đổi giá trị, và biến đổi thành luồng khác

map đơn giản: đổi từng giá trị. Nhóm còn lại (gọi chung là higher-order mapping — ánh xạ bậc cao) làm việc khó hơn: mỗi giá trị đến lại mở ra một luồng mới (thường là một request), và câu hỏi là xử lý sao khi luồng cũ chưa xong mà giá trị mới đã tới.

Toán tửKhi có giá trị mớiHợp với
switchMapHuỷ luồng cũ, chạy luồng mớiÔ tìm kiếm, lọc, đổi route
mergeMapChạy song song tất cảTải nhiều file cùng lúc
concatMapXếp hàng, xong cái này mới tới cái kiaGhi dữ liệu cần đúng thứ tự
exhaustMapBỏ qua giá trị mới nếu luồng cũ chưa xongNút Lưu chống bấm hai lần
 
tuKhoa$.pipe(
  debounceTime(300),
  distinctUntilChanged(),
  switchMap((tk) => this.api.tim(tk)),   // gõ tiếp → huỷ request cũ
).subscribe((kq) => this.ketQua.set(kq));

Bug kinh điển: dùng mergeMap cho ô tìm kiếm. Request cho "ab" có thể về sau request cho "abc", và kết quả cũ ghi đè kết quả mới — người dùng thấy danh sách không khớp từ khoá đang gõ. Đúng cho tình huống này là switchMap.

Được gì — mất gì

Ưu điểm và nhược điểm

+Mặt lợi

  • Diễn đạt được chính sách đồng thời chỉ bằng cách chọn đúng tên toán tử.
  • Tự huỷ request thừa với switchMap — bớt tải cho máy chủ, hết bug kết quả cũ đè kết quả mới.
  • Không cần cờ dangGui thủ công khi dùng exhaustMap.
  • Ghép chuỗi phụ thuộc gọn: lấy chi tiết sau khi có id, không lồng callback.

Ví dụ mặt lợi

tuKhoa$.pipe(switchMap((tk) => api.tim(tk)))
// Gõ "a" → "ab" → "abc": hai request đầu bị huỷ ngay,
// chỉ kết quả của "abc" được hiển thị. Không cần cờ, không cần đếm.

nutLuu$.pipe(exhaustMap(() => api.luu(dl)))
// Bấm Lưu 5 lần liên tiếp → chỉ 1 request được gửi.

−Mặt hại

  • Bốn cái tên rất dễ chọn nhầm, mà chọn nhầm thì bug chỉ hiện khi mạng chậm — khó tái hiện.
  • switchMap huỷ cả thao tác ghi. Dùng cho lệnh lưu là mất dữ liệu.
  • mergeMap không giới hạn có thể bắn hàng trăm request cùng lúc.
  • Lồng nhiều tầng làm luồng khó đọc và khó gỡ lỗi.

Ví dụ mặt hại

tuKhoa$.pipe(mergeMap((tk) => api.tim(tk)))
// ✗ request "ab" về SAU request "abc" → kết quả cũ ghi đè kết quả mới
// Người dùng thấy danh sách không khớp từ khoá đang gõ.
// Tệ nhất: chỉ xảy ra khi mạng chậm, máy dev không bao giờ tái hiện được.

nutLuu$.pipe(switchMap(() => api.luu(dl)))
// ✗ bấm Lưu lần hai huỷ lệnh lưu lần một đang chạy → mất dữ liệu
