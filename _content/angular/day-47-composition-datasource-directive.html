Là gì

Đưa việc lấy dữ liệu ra khỏi component

Mọi màn hình đều có những dropdown giống nhau: danh sách kho, danh sách đơn vị, danh mục trạng thái. Nếu mỗi component tự inject service, tự gọi API, tự gán vào options thì cùng một đoạn code bị chép hàng chục lần.

Giải pháp là composition (ghép chức năng) bằng directive: directive tự lấy dữ liệu rồi đặt vào component chủ.

@Directive({ selector: '[nguonKho]' })
export class NguonKhoDirective {
  private host = inject(SelectComponent, { host: true });
  private api = inject(DanhMucService);

  constructor() {
    this.api.dsKho()
      .pipe(takeUntilDestroyed())
      .subscribe((ds) => this.host.options.set(ds));
  }
}

<qp45-select formControlName="khoId" nguonKho />   // hết, không cần gì thêm

Angular 15+ còn có hostDirectives: gắn sẵn directive vào một component ngay tại nơi khai báo, để mọi nơi dùng component đó đều có hành vi kèm theo mà không phải nhớ gõ thêm thuộc tính.

Được gì — mất gì

Ưu điểm và nhược điểm

+Mặt lợi

  • Component form gọn hẳn: không còn hàng chục dòng nạp danh mục.
  • Sửa một chỗ, mọi màn được hưởng (đổi endpoint, thêm cache, thêm lọc theo quyền).
  • Ghép được nhiều directive trên cùng một ô: nguồn dữ liệu + tự động chọn + vô hiệu hoá.
  • Template đọc như mô tả yêu cầu: "ô này lấy nguồn kho".

Ví dụ mặt lợi

// Trước — lặp ở mọi màn
ngOnInit() { this.api.dsKho().subscribe((ds) => this.dsKho.set(ds)); }
<qp45-select [options]="dsKho()" formControlName="khoId" />

// Sau — thêm cache dùng chung chỉ phải sửa trong directive
<qp45-select formControlName="khoId" nguonKho />

−Mặt hại

  • Phép thuật ngầm. Nhìn template không biết dữ liệu từ đâu ra, người mới rất dễ bối rối.
  • Directive gắn chặt vào component chủ — đổi API của component là gãy directive.
  • Khó tuỳ biến từng chỗ: một màn cần lọc khác đi thì phải thêm input hoặc viết directive khác.
  • Mỗi ô một request nếu quên chia sẻ kết quả — ba dropdown là ba lần gọi cùng một API.

Ví dụ mặt hại

// 3 ô cùng nguồn → 3 request giống hệt nhau
<qp45-select nguonKho /> <qp45-select nguonKho /> <qp45-select nguonKho />

// chữa trong service:
dsKho$ = this.http.get(…).pipe(shareReplay({ bufferSize: 1, refCount: true }));

Từ điển

Thuật ngữ đã dùng

Thuật ngữNghĩa tiếng Việt
compositionGhép chức năng từ nhiều mảnh nhỏ thay vì kế thừa.
hostComponent/phần tử mà directive được gắn lên.
hostDirectivesKhai directive kèm sẵn cho một component.
datasourceNguồn dữ liệu cho một ô chọn/bảng.
shareReplayChia sẻ một lần gọi cho nhiều người đăng ký.
