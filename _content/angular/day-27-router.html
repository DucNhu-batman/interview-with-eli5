Một bảng tra: URL vào, component ra

Router (bộ định tuyến) giữ một danh sách route (tuyến): mỗi mục nói "đường dẫn này thì vẽ component kia vào <router-outlet>". Người dùng bấm link, URL đổi, router tra bảng rồi thay component — không tải lại trang.

export const routes: Routes = [
  { path: '', redirectTo: 'kho', pathMatch: 'full' },
  { path: 'kho', component: DsKhoComponent },
  { path: 'kho/:id', component: ChiTietKhoComponent },   // tham số đường dẫn
  { path: '**', component: KhongTimThayComponent },      // phải để cuối cùng
];

<a [routerLink]="['/kho', kho.id]" [queryParams]="{ tab: 'chung' }">Xem</a>
<a routerLink="/kho" routerLinkActive="dang-chon">Danh sách</a>

Đọc tham số ở phía component:

private route = inject(ActivatedRoute);
readonly id = toSignal(this.route.paramMap.pipe(map((p) => p.get('id'))));

Tham số đường dẫn hay query param? Cái xác định tài nguyên (id bản ghi) đi vào đường dẫn. Cái tuỳ chọn (trang, từ khoá, tab đang mở) đi vào query param — nhờ vậy người dùng chia sẻ link là giữ nguyên bộ lọc.

Được gì — mất gì

Ưu điểm và nhược điểm

+Mặt lợi

  • URL trở thành trạng thái chia sẻ được: gửi link cho đồng nghiệp là họ thấy đúng màn hình đó.
  • Nút Back/Forward của trình duyệt hoạt động đúng mà không phải viết gì thêm.
  • Chuyển màn mượt, giữ nguyên state chung và không tải lại toàn bộ ứng dụng.
  • Là điểm móc cho lazy loading, guard, resolver — mọi thứ về sau đều gắn vào bảng route.

Ví dụ mặt lợi

<a [routerLink]="['/kho', kho.id]" [queryParams]="{ tab: 'ton' }">Xem</a>
// URL: /kho/12?tab=ton — gửi cho đồng nghiệp là họ mở đúng màn đó,
// và nút Back của trình duyệt hoạt động đúng mà không viết thêm dòng nào.

−Mặt hại

  • Thứ tự route quan trọng. Đặt '**' nhầm chỗ là nuốt hết mọi đường dẫn phía sau.
  • Component không tự dựng lại khi chỉ đổi tham số trên cùng một route — phải lắng nghe paramMap.
  • Đường dẫn là chuỗi, gõ sai không ai báo cho tới lúc chạy.
  • Deep link cần máy chủ cấu hình đúng, nếu không F5 giữa chừng sẽ ra 404.

Ví dụ mặt hại

const routes = [
  { path: '**', component: KhongTimThay },   // ✗ đặt ĐẦU danh sách
  { path: 'kho', component: DsKho },        // không bao giờ tới được
];

// Và component không tự dựng lại khi chỉ đổi tham số:
// /kho/1 → /kho/2 : ngOnInit KHÔNG chạy lại, màn hình vẫn hiện kho 1
// chữa: lắng nghe route.paramMap thay vì đọc snapshot một lần

Từ điển

Thuật ngữ đã dùng

Thuật ngữNghĩa tiếng Việt
routerBộ định tuyến — ánh xạ URL sang component.
routeTuyến — một mục trong bảng định tuyến.
router-outletÔ chứa component của route hiện tại.
path paramTham số nằm trong đường dẫn, ví dụ /kho/12.
query paramTham số sau dấu ?, ví dụ ?trang=2.
ActivatedRouteĐối tượng mô tả route đang hoạt động.
deep linkLink trỏ thẳng vào một màn hình bên trong ứng dụng.
