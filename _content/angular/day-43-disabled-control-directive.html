Hai nguồn sự thật đánh nhau

Với reactive form, trạng thái bật/tắt thuộc về control, không thuộc về thẻ HTML. Viết [disabled]="dieuKien" là tạo ra nguồn sự thật thứ hai, và Angular in cảnh báo "It looks like you're using the disabled attribute with a reactive form directive".

Cách đúng theo tài liệu là gọi control.disable()/enable() trong lớp — nhưng viết trong template lại tiện hơn nhiều. Một directive nhỏ dung hoà được cả hai:

@Directive({ selector: '[formControl][qp45Disabled], [formControlName][qp45Disabled]' })
export class Qp45DisabledControl {
  private dir = inject(NgControl);
  qp45Disabled = input(false, { transform: booleanAttribute });

  constructor() {
    effect(() => {
      const c = this.dir.control;
      this.qp45Disabled() ? c?.disable({ emitEvent: false })
                          : c?.enable({ emitEvent: false });
    });
  }
}

<input formControlName="ma" [qp45Disabled]="!choPhepSua()" />

Được gì — mất gì

Ưu điểm và nhược điểm

+Mặt lợi

  • Khai báo ngay trong template nhưng vẫn đi qua API chính thức của control.
  • Hết cảnh báo trong console, không còn hai nguồn sự thật.
  • Dùng lại ở mọi form, không lặp enable/disable trong từng component.
  • emitEvent: false tránh kích hoạt valueChanges thừa.

Ví dụ mặt lợi

// Thay vì rải trong lớp:
if (!choPhepSua) form.controls.ma.disable();
else form.controls.ma.enable();
// … lặp lại ở mọi chỗ điều kiện đổi

// Chỉ còn một dòng trong template, luôn đồng bộ:
<input formControlName="ma" [qp45Disabled]="!choPhepSua()" />

−Mặt hại

  • Control bị vô hiệu biến mất khỏi form.value — đây là hành vi của Angular, directive không đổi được.
  • Thêm một khái niệm riêng của dự án, người mới phải học.
  • Dễ xung đột nếu nơi khác cũng gọi disable() trên chính control đó.
  • Vô hiệu hoá không phải là bảo mật: người dùng vẫn sửa được bằng công cụ trình duyệt.

Ví dụ mặt hại

<input formControlName="ma" [qp45Disabled]="true" />
api.capNhat(form.value);        // ✗ payload thiếu hẳn trường "ma"
api.capNhat(form.getRawValue()); // ✓

// Và máy chủ vẫn phải tự kiểm tra quyền sửa trường đó
