Template chỉ huy, TypeScript đứng ngoài

Với template-driven form (form điều khiển bởi template), bạn không tạo đối tượng form trong lớp. Chỉ cần ngModel trên mỗi ô nhập, Angular tự dựng FormControl tương ứng và gom vào NgForm.

<form #f="ngForm" (ngSubmit)="luu(f.value)">
  <input name="ten" [(ngModel)]="kho.ten" required minlength="3" #ten="ngModel" />

  @if (ten.invalid && ten.touched) {
    <small class="err">Tên phải có ít nhất 3 ký tự</small>
  }

  <button [disabled]="f.invalid">Lưu</button>
</form>

Thuộc tính name là bắt buộc — đó là khoá để Angular đăng ký control vào form. Trạng thái của control (valid, touched, dirty, errors) đọc trực tiếp trong template qua biến template.

Được gì — mất gì

Ưu điểm và nhược điểm

+Mặt lợi

  • Viết rất nhanh. Form đăng nhập, ô tìm kiếm, hộp thoại nhỏ — vài dòng là xong.
  • Gần với HTML thuần, người mới đọc hiểu ngay, dùng lại được thuộc tính chuẩn (required, maxlength).
  • Không phải đồng bộ hai nơi. Model và giao diện gắn thẳng với nhau.
  • Ít code trong lớp nên component gọn.

Ví dụ mặt lợi

<form #f="ngForm" (ngSubmit)="luu(f.value)">
  <input name="tuKhoa" [(ngModel)]="tuKhoa" required />
  <button [disabled]="f.invalid">Tìm</button>
</form>
// Toàn bộ form: 4 dòng HTML, 0 dòng TypeScript.

−Mặt hại

  • Khó kiểm thử. Muốn test phải dựng cả template, không test riêng logic form được.
  • Bất đồng bộ ngầm. Control được tạo sau khi template dựng xong, nên đụng vào quá sớm là undefined.
  • Validate động rất vất vả. Đổi luật theo điều kiện phải xoay xở bằng directive.
  • Không hợp form lớn. Form nhiều nhóm, mảng động, phụ thuộc chéo sẽ thành mớ bòng bong.
  • Kiểu dữ liệu yếu: f.value là any.

Ví dụ mặt hại

<input [(ngModel)]="kho.ten" required />     // ✗ thiếu name=""
// Error: If ngModel is used within a form tag, either the name attribute
// must be set or the form control must be defined as 'standalone'

const dl = f.value;    // kiểu any → gõ sai tên trường không ai báo
api.tao(dl.tenKho);    // undefined, lỗi hiện ở tận backend

Từ điển

Thuật ngữ đã dùng

Thuật ngữNghĩa tiếng Việt
template-driven formForm khai báo trong template bằng ngModel.
NgFormDirective gom các control trong một thẻ form.
FormControlĐối tượng đại diện một ô nhập (giá trị + trạng thái).
touched / dirtyĐã từng chạm vào / đã từng sửa giá trị.
validatorHàm kiểm tra tính hợp lệ của giá trị.
