Là gì

Một khuôn, nhiều bản

Bạn viết giao diện cho một phần tử; Angular nhân bản khuôn đó cho từng phần tử trong danh sách và bơm dữ liệu vào.

@for (sp of danhSach(); track sp.id) {
  <app-the-san-pham [sp]="sp" />
} @empty {
  <p>Chưa có sản phẩm nào</p>
}

// Cú pháp cũ
<li *ngFor="let sp of danhSach(); index as i; trackBy: trackById">
  {{ i + 1 }}. {{ sp.ten }}
</li>

Các biến ngữ cảnh dùng được: $index, $first, $last, $even, $odd, $count.

Trọng tâm

track / trackBy: vì sao bắt buộc

Khi danh sách đổi, Angular phải quyết định dòng nào giữ, dòng nào vẽ lại. Mặc định nó so sánh theo tham chiếu object. Gọi API lấy lại danh sách là mọi object đều mới → toàn bộ dòng bị huỷ và dựng lại, dù nội dung y hệt.

Khai track sp.id là bảo Angular: "hãy nhận dạng dòng bằng id". Nó sẽ giữ nguyên các dòng cũ, chỉ chạm vào dòng thật sự đổi.

Đừng track theo $index khi danh sách có thể chèn/xoá/sắp xếp — vị trí thay đổi sẽ khiến Angular nhận nhầm dòng, gây hiện tượng ô nhập giữ sai giá trị. Ở Angular 17+, track là bắt buộc — đây là một quyết định thiết kế có chủ ý.

Được gì — mất gì

Ưu điểm và nhược điểm

+Mặt lợi

  • Giao diện luôn khớp dữ liệu. Sửa mảng là danh sách tự cập nhật.
  • Cập nhật tối thiểu nhờ track. Nghìn dòng nhưng chỉ vẽ lại dòng đổi.
  • @empty gọn gàng — hết cảnh thêm một *ngIf riêng cho trạng thái rỗng.
  • Có sẵn biến vị trí cho việc đánh số, tô màu xen kẽ, xử lý phần tử cuối.

Ví dụ mặt lợi

@for (sp of danhSach(); track sp.id) { <app-dong [sp]="sp" /> }

// Gọi API lấy lại 500 dòng, chỉ 1 dòng đổi giá:
// → Angular giữ nguyên 499 phần tử DOM, chỉ vẽ lại đúng 1 dòng

−Mặt hại

  • Danh sách lớn thì chậm. Vài nghìn dòng nên chuyển sang cuộn ảo (virtual scroll) của Angular CDK.
  • Track sai còn hại hơn không track. Trùng khoá gây lỗi khó lần.
  • Gọi hàm/pipe không thuần trong vòng lặp nhân chi phí lên theo số dòng.
  • Sửa mảng tại chỗ (push) không tạo tham chiếu mới — với OnPush hoặc signal thì giao diện không cập nhật.

Ví dụ mặt hại

@for (o of dongs(); track $index) { <input [formControl]="o" /> }
// Xoá dòng thứ 2 trong danh sách 5 dòng:
// ✗ các ô nhập bên dưới giữ nguyên giá trị cũ, lệch hẳn với dữ liệu

this.items().push(moi);      // ✗ sửa tại chỗ, tham chiếu không đổi
this.items.update((ds) => [...ds, moi]);   // ✓ giao diện mới cập nhật
