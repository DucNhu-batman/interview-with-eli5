Vì sao không nên inject ActivatedRoute khắp nơi

Đọc route.paramMap trong từng component nghe có vẻ vô hại, nhưng nó buộc component phải biết mình đang nằm ở đâu trong bảng route. Muốn dùng lại component đó trong một dialog hay một tab thì không được nữa, và mỗi bài test đều phải giả lập ActivatedRoute.

// Cách 1 — provider gói sẵn, component chỉ inject cái nó cần
export const KHO_ID = new InjectionToken<Signal<string>>('KHO_ID');

{
  path: ':id',
  component: ChiTietKhoComponent,
  providers: [{
    provide: KHO_ID,
    useFactory: () => toSignal(inject(ActivatedRoute).paramMap.pipe(map((p) => p.get('id')!))),
  }],
}

export class ChiTietKhoComponent {
  readonly id = inject(KHO_ID);   // không biết gì về router
}
// Cách 2 — gọn hơn nữa: bật input binding, tham số chảy thẳng vào input
provideRouter(routes, withComponentInputBinding());

export class ChiTietKhoComponent {
  id = input.required<string>();   // khớp tên tham số route
}

Được gì — mất gì

Ưu điểm và nhược điểm

+Mặt lợi

  • Component dùng lại được ở mọi ngữ cảnh — trang, tab, dialog — vì nó chỉ nhận dữ liệu.
  • Test đơn giản hẳn: truyền một input thay vì dựng cả router giả.
  • Logic đọc route nằm một chỗ, đổi tên tham số chỉ sửa ở route.
  • Ghép được với resolver để component nhận thẳng dữ liệu đã tải xong.

Ví dụ mặt lợi

// Test trước: phải giả lập cả ActivatedRoute
providers: [{ provide: ActivatedRoute, useValue: { paramMap: of(…) } }]

// Test sau: một dòng
fixture.componentRef.setInput('id', 'KHO-0001');

−Mặt hại

  • Thêm một lớp trung gian cho việc vốn chỉ một dòng — với màn nhỏ là thừa.
  • Ràng buộc theo tên ngầm. Input phải trùng tên tham số route, gõ lệch là im lặng không có dữ liệu.
  • Không phải cấu hình mặc định: quên bật withComponentInputBinding() là mọi input route đều rỗng.
  • Provider theo route dễ bị nhân bản nếu khai nhầm cấp.

Ví dụ mặt hại

{ path: ':khoId', component: ChiTietKhoComponent }
export class ChiTietKhoComponent { id = input.required<string>(); }
// tên lệch (khoId ≠ id) → input không bao giờ nhận giá trị
// và lỗi chỉ lộ ra lúc chạy, không có cảnh báo biên dịch

Từ điển

Thuật ngữ đã dùng

Thuật ngữNghĩa tiếng Việt
ActivatedRouteĐối tượng mô tả route đang hoạt động.
InjectionTokenToken tự tạo để cung cấp một giá trị qua DI.
useFactoryProvider tạo giá trị bằng một hàm.
withComponentInputBindingBơm tham số route thẳng vào input cùng tên.
toSignalChuyển observable thành signal.
