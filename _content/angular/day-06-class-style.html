Là gì

Directive không đổi cấu trúc, chỉ đổi diện mạo

Attribute directive (chỉ thị thuộc tính) không thêm bớt phần tử — nó sửa bản thân phần tử: class, style, thuộc tính, hành vi. NgClass và NgStyle là hai cái có sẵn hay dùng nhất.

// Cách gọn nhất — không cần import gì
<div [class.active]="dangChon()" [class.disabled]="!choPhep()">…</div>
<div [style.width.px]="chieuRong()">…</div>

// NgClass / NgStyle — khi số lượng class động, tính bằng object
<div [ngClass]="{ active: dangChon(), 'text-error': coLoi() }">…</div>
<div [ngStyle]="{ width: w() + 'px', color: mau() }">…</div>

Ưu tiên [class.x] và [style.x] cho các trường hợp cố định — cú pháp này được Angular tối ưu riêng, không cần import NgClass/NgStyle, và đọc rõ ràng hơn. Chỉ dùng ngClass khi tập class thật sự sinh động lúc chạy.

Được gì — mất gì

Ưu điểm và nhược điểm

+Mặt lợi

  • Giao diện phản ứng theo state mà không phải viết một dòng thao tác DOM.
  • Cộng dồn an toàn. Angular chỉ thêm/bớt đúng class nó quản lý, không xoá class do nơi khác gắn.
  • Kết hợp tốt với hệ token. Bật tắt class tiện ích (Tailwind) theo điều kiện rất gọn.
  • Viết được directive riêng. Cùng cơ chế đó, bạn tự tạo được chỉ thị dùng chung (ví dụ tô màu theo trạng thái).

Ví dụ mặt lợi

<tr [class.bg-error-25]="row.quaHan"
    [class.opacity-50]="!row.active">…</tr>
// Trạng thái đổi → class tự thêm/bớt, class tĩnh trên thẻ vẫn giữ nguyên

−Mặt hại

  • Object literal trong template tạo tham chiếu mới mỗi chu kỳ → tốn thêm công so sánh.
  • ngStyle đẻ ra inline style, đè lên stylesheet và khó ghi đè lại về sau.
  • Trộn nhiều nguồn class (class tĩnh + [class] + ngClass) khiến khó đoán kết quả cuối.
  • Dễ nhồi logic vào template — điều kiện dài nên chuyển thành computed() trong lớp.

Ví dụ mặt hại

<div [ngClass]="{ active: dangChon(), err: coLoi() }">
// ✗ object literal: mỗi chu kỳ tạo object MỚI → Angular phải so lại toàn bộ

<div [ngStyle]="{ color: '#98A2B3' }">
// ✗ inline style + hardcode màu: theme tối hiện chữ xám trên nền xám,
// và không ghi đè lại được bằng stylesheet

Đừng hardcode màu. Trong dự án này, mọi màu phải lấy từ token trong tailwind.config.js (text-gray-400, bg-brand-25…), không viết [style.color]="'#98A2B3'" — theme đổi là mọi chỗ hardcode đều sai.

Từ điển

Thuật ngữ đã dùng

Thuật ngữNghĩa tiếng Việt
attribute directiveChỉ thị thuộc tính — sửa diện mạo/hành vi của phần tử sẵn có.
NgClass / NgStyleDirective gán nhiều class/style theo object điều kiện.
inline styleStyle viết thẳng trên phần tử, độ ưu tiên rất cao.
design tokenGiá trị thiết kế đặt tên sẵn (màu, cỡ chữ) dùng chung toàn hệ thống.
computed()Signal dẫn xuất — giá trị tính từ signal khác, tự cache.
