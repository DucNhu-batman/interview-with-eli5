EventEmitter vốn dĩ là một Subject

EventEmitter kế thừa từ Subject của RxJS, nên bất cứ observable nào cũng đóng vai output được. Angular hiện đại có outputFromObservable() làm việc đó một cách chính thức.

export class OTimKiem {
  private go$ = new Subject<string>();

  // Cổng ra đã được lọc sẵn: bên ngoài chỉ nhận từ khoá "đáng gọi API"
  readonly tim = outputFromObservable(
    this.go$.pipe(
      map((v) => v.trim()),
      filter((v) => v.length >= 2),
      debounceTime(300),
      distinctUntilChanged(),
    ),
  );

  onInput(v: string) { this.go$.next(v); }
}

Chiều ngược lại cũng có: outputToObservable(ref.instance.tim) biến một output thành observable để ghép tiếp vào chuỗi RxJS ở phía cha.

Được gì — mất gì

Ưu điểm và nhược điểm

+Mặt lợi

  • Logic lọc nằm cùng chỗ với component phát ra nó, mọi nơi dùng đều được hưởng.
  • Cha không phải lặp lại debounceTime ở từng màn hình.
  • Tự huỷ đăng ký theo vòng đời component.
  • Test được luồng đầu ra mà không cần dựng template.

Ví dụ mặt lợi

// Trước: mỗi màn tự lặp lại
<qp45-o-tim (tim)="tk$.next($event)" />
tk$.pipe(debounceTime(300), distinctUntilChanged()).subscribe(…);

// Sau: mọi màn chỉ còn một dòng, không ai quên chống dội nữa
<qp45-o-tim (tim)="facade.tim($event)" />

−Mặt hại

  • Hành vi bị giấu. Cha thấy sự kiện tới trễ 300ms mà không hiểu vì sao — phải đọc code con.
  • Không tuỳ chỉnh được từ ngoài. Màn nào muốn phản hồi tức thì thì chịu.
  • Kéo RxJS vào một component đơn giản, nặng hơn mức cần thiết.
  • Luồng lỗi làm chết output. Một lỗi lọt vào là cổng ra im lặng vĩnh viễn.

Ví dụ mặt hại

// Một lỗi trong pipe → output ngừng phát, không ai biết
this.go$.pipe(map((v) => v.toUpperCase()))   // v là null → TypeError
// chữa: thêm catchError, hoặc lọc null trước khi map

// Màn "quét mã vạch" cần phản hồi tức thì
// nhưng vẫn bị chờ 300ms vì luật nằm trong component con

Thuật ngữNghĩa tiếng Việt
outputFromObservableTạo output từ một observable có sẵn.
outputToObservableBiến một output thành observable.
SubjectVừa là luồng vừa là nơi phát giá trị.
debounceTimeChờ im lặng đủ lâu mới phát giá trị cuối.
