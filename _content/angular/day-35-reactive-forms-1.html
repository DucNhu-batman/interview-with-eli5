Form là một đối tượng, không phải mấy thẻ input

Với reactive form (form phản ứng), bạn khai cấu trúc form trong lớp trước, rồi mới nối vào template. Nguồn sự thật nằm ở TypeScript — template chỉ là cái vỏ.

private fb = inject(FormBuilder);

readonly form = this.fb.group({
  ma: ['', [Validators.required, Validators.pattern(/^KHO-\d{4}$/)]],
  ten: ['', [Validators.required, Validators.maxLength(100)]],
  dienTich: [null as number | null],
  hoatDong: [true],
});

luu() {
  if (this.form.invalid) { this.form.markAllAsTouched(); return; }
  this.api.tao(this.form.getRawValue()).subscribe(…);
}
<form [formGroup]="form" (ngSubmit)="luu()">
  <input formControlName="ma" />
  @if (form.controls.ma.touched && form.controls.ma.errors?.['required']) {
    <small>Mã kho là bắt buộc</small>
  }
</form>

Được gì — mất gì

Ưu điểm và nhược điểm

+Mặt lợi

  • Điều khiển được bằng code: đặt giá trị, bật/tắt, reset, thêm bớt control lúc chạy.
  • Test không cần giao diện. Dựng form, gán giá trị, kiểm tra valid — xong.
  • Kiểu chặt. Form typed cho biết chính xác value có những trường gì.
  • valueChanges là một observable — ghép thẳng vào RxJS để lọc, chống dội, gọi API.

Ví dụ mặt lợi

// Test chạy trong mili-giây, không cần dựng template
form.patchValue({ ma: 'KHO-01' });
expect(form.controls.ma.valid).toBe(false);   // sai định dạng → bắt được ngay

// Và nối thẳng vào RxJS
form.controls.ten.valueChanges.pipe(debounceTime(300))
  .subscribe((v) => this.kiemTraTrung(v));

−Mặt hại

  • Nhiều code hơn. Một form ba ô cũng phải khai ở hai nơi.
  • Phải tự đồng bộ template. Gõ sai formControlName là lỗi lúc chạy, không phải lúc build.
  • Dễ quên markAllAsTouched nên bấm Lưu mà không thấy lỗi nào hiện ra.
  • disabled control bị loại khỏi value — gửi lên máy chủ thiếu trường mà không ai báo.

Ví dụ mặt hại

form.controls.ma.disable();
console.log(form.value);        // { ten: …, dienTich: … } — MẤT trường ma!
console.log(form.getRawValue()); // { ma: …, ten: … } — phải dùng cái này

<input formControlName="maKho" />   // gõ nhầm tên → lỗi lúc chạy:
// Cannot find control with name: 'maKho'

Từ điển

Thuật ngữ đã dùng

Thuật ngữNghĩa tiếng Việt
reactive formForm dựng bằng code, template chỉ nối vào.
FormBuilderTiện ích tạo form ngắn gọn.
FormGroup / FormControlNhóm control / một ô nhập.
getRawValue()Lấy giá trị kể cả các control đang bị vô hiệu hoá.
markAllAsTouchedĐánh dấu đã chạm mọi ô để lỗi hiện ra.
typed formForm có kiểu chặt chẽ (từ Angular 14).
