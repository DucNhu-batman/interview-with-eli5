Day 36 — Reactive Forms, phần 2

FormArray cho danh sách động, validator cấp nhóm cho luật liên trường, và cách bật/tắt luật khi form đổi hình theo lựa chọn của người dùng.

Danh sách động

FormArray

FormArray là một danh sách control thêm bớt được lúc chạy — đúng cho những màn "thêm dòng chi tiết".

readonly form = this.fb.group({
  ten: ['', Validators.required],
  dongs: this.fb.array([this.taoDong()]),
});
get dongs() { return this.form.controls.dongs; }
taoDong() { return this.fb.group({ sp: [null, Validators.required], sl: [1] }); }
themDong() { this.dongs.push(this.taoDong()); }
xoaDong(i: number) { this.dongs.removeAt(i); }
<div formArrayName="dongs">
  @for (d of dongs.controls; track d; let i = $index) {
    <div [formGroupName]="i">
      <input formControlName="sl" />
      <button type="button" (click)="xoaDong(i)">Xoá</button>
    </div>
  }
</div>

Luật liên trường

Validator ở cấp nhóm và luật đổi theo điều kiện

// Ngày kết thúc phải sau ngày bắt đầu — luật của cả nhóm, không của một ô
const khoangNgay: ValidatorFn = (g) => {
  const { tuNgay, denNgay } = (g as FormGroup).value;
  return tuNgay && denNgay && denNgay < tuNgay ? { khoangNgay: true } : null;
};

// Đổi luật khi người dùng chọn loại khác
this.form.controls.loai.valueChanges.subscribe((loai) => {
  const c = this.form.controls.maSoThue;
  loai === 'DOANH_NGHIEP' ? c.addValidators(Validators.required) : c.clearValidators();
  c.updateValueAndValidity();        // BẮT BUỘC, nếu không luật mới không có hiệu lực
});

Được gì — mất gì

Ưu điểm và nhược điểm

+Mặt lợi

  • Form đổi hình theo dữ liệu mà vẫn giữ được một nguồn sự thật duy nhất.
  • Luật liên trường đặt đúng chỗ — ở nhóm, không phải nhét vào một ô bất kỳ.
  • Thêm/xoá dòng an toàn, trạng thái hợp lệ của cả form tự cập nhật theo.
  • Tái sử dụng nhóm con: một FormGroup địa chỉ dùng lại ở nhiều form.

Ví dụ mặt lợi

// Thêm 3 dòng, form tự biết còn thiếu dữ liệu
themDong(); themDong();
expect(form.valid).toBe(false);      // dòng mới chưa chọn sản phẩm

// Xoá dòng lỗi, form hợp lệ trở lại — không cần cờ thủ công nào
xoaDong(2);
expect(form.valid).toBe(true);

−Mặt hại

  • Quên updateValueAndValidity() là luật mới không chạy — bug im lặng hay gặp nhất.
  • Template lồng ba tầng (formArrayName → formGroupName → formControlName) rất dễ sai.
  • Track theo $index trong FormArray làm ô nhập giữ sai giá trị khi xoá dòng giữa.
  • Nhiều valueChanges lồng nhau có thể tạo vòng cập nhật vô tận.

Ví dụ mặt hại

c.addValidators(Validators.required);
// thiếu dòng dưới → form vẫn báo hợp lệ dù ô đang rỗng
// c.updateValueAndValidity();

// Vòng lặp vô tận:
a.valueChanges.subscribe((v) => b.setValue(v));
b.valueChanges.subscribe((v) => a.setValue(v));   // ✗ đứng máy
// chữa: setValue(v, { emitEvent: false })
